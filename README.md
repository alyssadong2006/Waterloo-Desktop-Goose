# Desktop Goose 🪿

A Canada goose that lives on your screen, walks around, and perches on window title bars / tab
strips. It wears the University of Waterloo seal on its flank, like a cutie mark.

Native builds are included for **macOS 12+** (Apple Silicon and Intel) and **Windows 10/11**
(x64 and ARM64). Neither build requires accessibility or administrator permission.

## Run / stop on macOS
Double-click **Goose** on the Desktop (a shortcut to `Goose.app`). Double-click it again to put
the goose away, again to let it back out.

Or press **⌥⌘G** anywhere — same toggle, system-wide. Or use the 🪿 menu bar item.
"Put goose away" hides and freezes it (the menu bar icon dims); **Quit goose** exits for real.

    open ~/desktop-goose/Goose.app     # from the terminal

### Build for macOS

The build script creates one universal `Goose.app` for both Apple Silicon and Intel Macs. Xcode
Command Line Tools are required.

    ~/desktop-goose/build.sh

## Run / stop on Windows

Download/extract `Goose-win-x64.zip` (most PCs) or `Goose-win-arm64.zip`, then double-click
`DesktopGoose.exe`. Windows may show a SmartScreen warning for a locally built, unsigned app;
choose **More info → Run anyway**. Use the goose tray icon to control or quit it.

- **Ctrl+Alt+G** puts the goose away or lets it back out.
- **Ctrl+Alt+F** drops or moves a fish at the cursor.
- Left-click pets the goose; drag and throw the goose, fish, eggs, or goslings.
- Right-click the goose opens the tray menu.
- A compact **Desktop Goose controls** window opens with the game, with buttons for the common
  actions and checkboxes for Follow, Stretchy mode, and sound. Closing it only hides it; reopen
  it from the goose icon in the Windows system tray.

The Windows version uses WinForms and Win32 window geometry so it remains lightweight and can
perch on ordinary window title bars without screen-capture permissions. Its goose, fish, eggs,
goslings, wizard hat, magic circles, and animation frames are generated directly from the
canonical pixel grids in `pixel_art.swift` and `coyote_art.swift`, so both builds use the same figures
and palette.

### Build for Windows

Install the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0), open PowerShell in
this folder, and run:

    .\build-windows.ps1                 # Windows x64 (default)
    .\build-windows.ps1 win-arm64       # Windows ARM64

This produces a self-contained, single-file executable and zip under `dist/`; the target PC does
not need .NET installed. Windows builds should be produced on Windows. After changing pixel art
in `pixel_art.swift` or `coyote_art.swift`, run `python tools/sync-pixel-art.py` before building to refresh the generated
Windows sprite table. `python tools/sync-pixel-art.py --check` verifies that all Windows sprites and palette entries
match the canonical Swift art without modifying any files.

## Art
Pixel sprites, composed at runtime from parts (head / neck / body / wing / legs / beak) so poses
animate: walk cycle, blink, peck, honk with a split bill, wing flap, dangle-when-held, hearts,
a brows-down angry head, and the fish, whose tail flaps faster the harder you swing it.

Canada goose colouring: black head, neck, bill and legs (`N`), the white chinstrap up the cheek
(`W`), brown back (`T`) over a pale breast (`U`) with a white undertail, darker wing (`V`),
crimson (`M`) for the crest lions and pink (`P`) for the cheek. The orange bill and blue-grey
shade from the old white goose are still in `Pal` but nothing draws them any more.

Proportions are deliberately chibi rather than accurate: a big round head low on a short thick
neck, an oversized eye with a glint, a stubby bill and a chubby body. A realistically-proportioned
Canada goose — small head, long thin neck, small eye, long bill — was correct and looked awful.

**Resolution.** `PIX` is 1.5, i.e. the sprite grid is 64x58 at half a point per pixel, so the bird
is the same size on screen as it was at `PIX` 3 / 32x29 but carries four times the pixels. That
only lands on whole device pixels on a 2x (Retina) display — on a 1x screen the cells alternate
between one and two pixels and the bird looks slightly uneven. Speech bubbles render at `TEXT_PIX`
(3) instead, so the pixel font stays legible rather than shrinking with the art.

The organic shapes (body, head, fish) are not hand-typed — `composeGoose` just stamps them, but
they were generated from silhouette functions so the 1px outline is exact and 1px spikes are
pruned. Hand-editing a row is fine; just keep every row the same length.

**The seal** (`Art.tag`) is the round University of Waterloo mark, 17x17, generated by `seal()` in
the art script: black lettering ring, white field, gold shield with a white-edged black chevron,
two crimson lions above it and one below. The "UNIVERSITY OF WATERLOO / CONCORDIA CUM VERITATE"
lettering itself is *not* there — the band is only two pixels thick, so the generator tries to
place pale tick marks for it and rejects every one that would notch the outer edge of the circle.
At this size a solid ring reads as a seal; broken-up ticks just read as a cog.

It is left-right symmetric on purpose (the generator forces it), because the whole sprite gets
mirrored when the goose turns around and an asymmetric mark would read backwards half the time.

`composeGoose` stamps the mark **before** the wing, so the folded wing lies over its leading edge
the way it would on a real bird. Stamp order there is the whole depth model — body, tail, mark,
wing, head — so moving a `c.stamp` line changes what sits on top of what.
`CANVAS_PAD` keeps spare rows above the head — without it a head that lifts during a honk gets
sliced off by the top of the canvas.
Everything lives in `enum Art` in `pixel_art.swift` as strings — one character per pixel, palette
in `enum Pal`. `PIX` is the pixel size in points.

Preview every pose as a sheet without launching the app:

    ~/desktop-goose/Goose.app/Contents/MacOS/Goose --sheet /tmp/sheet.png && open /tmp/sheet.png

The app icon is the same sprite, rendered by the binary at build time (`--iconset`) and packed
with `iconutil`.

## Interacting
- **Drag it** — pick the goose up; it flails and honks. Fling it and it flies off with the throw.
- **Stretchy mode** (optional, in the goose menu) gives its neck rubber-sling physics. Grab its
  head and the body trails and bounces; grab its body and the head does. The loose end keeps
  wobbling briefly after release, then settles back into its ordinary pose.
- **Click it** — a pet. It honks a heart at you.
- **Right-click it** — the same menu as the menu bar.
- Only the ~68×96px patch around the bird catches clicks; everywhere else the window is
  click-through, and the panel is non-activating so clicking never steals focus from your app.

## Feeding it 🐟
Press **⌥⌘F** (or 🪿 ▸ Drop a fish) and a fish lands under your cursor. Drag the fish around and
the goose drops everything to chase it — runs it down, hops when it is just out of reach, takes
off and flies when you dangle it high, and if it is perched on a tab bar with the fish below it,
swoops down off the ledge and lands next to it. Get it close enough and it
dips its head, snaps, and swallows it with a **YUM!** and a few hearts. It can also grab the fish
out of the air mid-jump, so teasing it works.

The fish is a real object: let go and it falls, bounces once, and settles on the floor or on any
window title bar — park it on a tab strip and the goose has to climb for it. Pressing ⌥⌘F again
moves the fish to wherever your cursor is now; **Take the fish away** removes it. The menu keeps a
count of how many it has eaten.

### Losing its temper
Keep the fish away from it and it gets cross. Anger builds while it is chasing and gets nowhere
(~11s), jumps every time it snaps at thin air because you moved the fish, and again every time it
lands empty-beaked — so actively teasing it boils it over in about five seconds. An angry goose
gets brows-down and a popping vein over its head, honks
**HONK!!!** / **GRR!** / **!!!** at you, runs ~50% faster and jumps again sooner. Feeding it
resets it instantly; taking the fish away leaves it grumbling for a few seconds before it calms
down. Tuning constants are `ANGER_FUSE` / `ANGER_MISS` / `ANGER_WHIFF`.

Park the fish somewhere genuinely unreachable and the goose *will* keep flinging itself at it
forever, angrily — that's on you. Take the fish away.

The fish gets its own borderless panel (same click-through trick as the goose) so you can drag it
over any app. Only one fish exists at a time.

## Eggs and goslings 🥚
**Lay an egg** (🪿 menu) and the goose squats and drops one. It falls and settles on the floor or
a title bar like the fish does. **Click the egg** and it cracks, shakes for a moment, and hatches
into a gosling; the cursor turns into a pointing hand over an egg so you can tell it is clickable.
Up to six eggs and eight goslings at once.

Goslings trot after the goose in a line, each keeping station a bit further back than the one in
front. They walk off ledges after it and scramble upward when it hops somewhere they can reach.
They are **deliberately slower than the goose** — it runs at 175 and flies, they toddle at 64 and
scurry at up to 154 — so they straggle when it bolts and reel back in once it settles. A gosling
that has been more than 700px adrift for 12 seconds gives up and scampers back into shot, so you
can never lose one for good.

**Drag a gosling** and it dangles from the cursor kicking its legs, and the goose honks about it.
Let go and it drops, bounces to a stop wherever it lands, and trots back. Throwing one is fine —
it stays on screen and rights itself.

### Optional coyote encounter 🐺

Choose **Spawn coyote** from the goose menu to start an encounter, and **Despawn coyote** to end
it. The slightly larger pixel coyote wears a circular University of Toronto seal on its flank.
Like the goslings, it puts on a wizard hat and opens matching rune circles when it teleports to a
target it cannot reach normally.

While it is present, health bars appear over the coyote and every gosling. Goslings actively run
away; mother becomes visibly angry, honks, and pursues the coyote to protect them. A gosling can
take three bites before it disappears. The coyote takes ten hits from mother, and each successful
gosling bite restores one of its health points, up to ten. Despawning it removes the encounter
immediately without affecting the goslings.

### Gosling wizardry 🪄
A gosling stuck somewhere it cannot walk to tries for three and a half seconds, gives up, and
**becomes a wizard**. Stuck means: mother is up a tab bar higher than it can hop; mother is well
below it but still under the ledge it is standing on, so walking toward her never takes it off the
edge; or mother is most of a screen away. If she is below it but *past the end* of its ledge it
just toddles off and drops, which is nicer than a spell, so that case is excluded on purpose. A pointy hat pops onto its
head, a rune circle winds up under its feet, a second circle opens *at the destination first*, and
then it thins out, steps through, and reappears over there. The circles fade, and the hat stays on
for another three and a half seconds before slowly fading away, so for a little while afterwards
you have an ordinary gosling toddling around in a wizard hat. Six second cooldown, so it will not
spam it.

Timings are `CAST_CHARGE` / `CAST_JUMP` / `CAST_TOTAL` / `HAT_FADE` / `CAST_COOL`. The near circle
is drawn in the gosling's own window; the far one gets a second window (`spell`) parked at the
destination, which is why each gosling owns two panels.

The menu lists them one per row — `✕ Gosling 3` — and clicking a row shoos that one; **Shoo them
all** clears the lot. Each egg and each gosling gets its own click-through panel, same trick as
the goose and the fish.

## Menu bar (🪿)
Put goose away (⌥⌘G) · Honk · Hop · Fly somewhere · Come here · Drop a fish (⌥⌘F) ·
Take the fish away · Lay an egg · Spawn/Despawn coyote · Screen ▸ · Follow my cursor · Honk sounds ·
✕ Gosling 1, ✕ Gosling 2, … · Shoo them all · Quit goose

Both hotkeys (⌥⌘G goose, ⌥⌘F fish) are registered with Carbon's `RegisterEventHotKey`, so they need
no accessibility permission — but they do win over the frontmost app's own ⌥⌘G / ⌥⌘F. To change
them, edit the `installHotKeys([...])` call in `applicationDidFinishLaunching` (`kVK_ANSI_G`,
`kVK_ANSI_F`; the modifiers are `optionKey | cmdKey` for both).

## How the perching works
Every 0.9s it reads `CGWindowListCopyWindowInfo` for on-screen windows, takes the *visible*
slices of each window's top edge (subtracting whatever is in front of it), and treats those as
ledges. It walks along them, hops between nearby ones, and flies up to far ones. No accessibility
or screen-recording permission needed — only window geometry is read, never contents or titles.

Windows are re-scanned continuously, so if you close or move a window out from under it, the
goose falls.

Both panels are `FreePanel`, which overrides `constrainFrameRect` to a no-op. **Do not remove
this.** AppKit otherwise refuses to let a window's frame cross the top of the visible screen, which
pins the panel in place whenever the goose is perched high on a tab bar — it is then drawn well
below where it actually is, cannot be dragged (the clickable patch is computed from where the code
*thinks* it is), and appears not to hop at all: it tucks its legs and goes nowhere.
